# tmux 사용 가이드 — 팀 세션 운영

> 이 저장소의 `setup-team` 으로 띄운 팀 세션을 다루는 방법입니다. 단축키는 현재 `~/.tmux.conf` 기준입니다
> (prefix `Ctrl+b`, 마우스 켜짐, 창·페인 번호 1부터, vi 복사 모드).

## 1. 핵심 개념

| 용어 | 뜻 | 팀 세션에서 |
|---|---|---|
| 세션 | tmux 작업 묶음. 터미널을 닫아도 살아 있다 | 팀 하나 = 세션 하나 (`discovery`, `shop`, `mygame` …) |
| 창 (window) | 세션 안의 탭 | 팀 설정의 `[창이름]` — 발견 팀은 `발견` 1개, 프로젝트 팀은 단계별 `기획`·`설계`·`개발`·`검증`·`전달`(게임은 `아트` 추가) |
| 페인 (pane) | 창을 나눈 칸 | 멤버 한 명 = 페인 하나. 위쪽 테두리에 멤버 라벨이 보인다 |
| prefix | 모든 단축키의 시작 키 | **`Ctrl+b`** 를 누르고 손을 뗀 뒤 다음 키를 누른다 |

> 표기: `prefix d` = `Ctrl+b` 를 눌렀다 떼고 `d`.

## 2. 팀 세션 시작·접속·종료

```bash
# 띄우기 (-c 생략 = 발견 팀)
setup-team discovery -d ~/MyProject/discovery
setup-team shop   -d ~/MyProject/shop    -c web-service
setup-team mygame -d ~/MyProject/mygame  -c game

tmux ls                     # 떠 있는 세션 목록
tmux attach -t discovery   # 세션 접속
```

| 동작 | 방법 |
|---|---|
| 세션에서 빠져나오기 (팀은 계속 동작) | `prefix d` |
| 다른 세션으로 이동 | `prefix s` → 목록에서 선택 / `prefix (` · `prefix )` 이전·다음 세션 |
| 세션 완전히 종료 (멤버 전원 종료) | `tmux kill-session -t discovery` |
| 같은 이름으로 다시 띄우기 | `setup-team discovery …` — 기존 세션이 있으면 재생성 여부를 묻는다 |

- 빠져나와도(detach) 멤버들은 작업을 계속합니다. 터미널을 닫거나 Mac 을 잠가도 됩니다(재부팅·로그아웃 시에는 종료).
- 여러 팀을 동시에 띄울 수 있지만 Codex 사용 한도를 함께 씁니다 — `team-status --limits` 로 확인.

## 3. 창 이동 (기획 ↔ 개발)

| 동작 | 단축키 |
|---|---|
| 1번 창 / 2번 창 | `prefix 1` / `prefix 2` |
| 다음 / 이전 창 | `prefix n` / `prefix p` |
| 창·페인 전체 트리에서 고르기 | `prefix w` (세션·창·페인을 미리보기와 함께 선택) |
| 하단 상태줄의 창 이름 클릭 | 마우스로 이동 |

## 4. 페인(멤버) 이동과 보기

| 동작 | 단축키 |
|---|---|
| 페인 선택 | **마우스 클릭** (가장 간단) |
| 방향으로 이동 | `prefix h` `j` `k` `l` (왼쪽·아래·위·오른쪽) |
| 페인 번호 표시 후 선택 | `prefix q` → 번호 키 |
| 한 페인을 전체 화면으로 / 원래대로 | **`prefix z`** (멤버 화면을 크게 볼 때) |
| 페인 크기 조절 | `prefix H` `J` `K` `L` (반복 입력 가능, 5칸씩) 또는 테두리 마우스 드래그 |

- 페인 위쪽 테두리의 라벨(예: `진행 클로드`, `보안 코덱스`)로 누구인지 확인합니다.
- `prefix q` 의 번호는 tmux 페인 번호이고, `team-status` 의 `pN` 은 팀 설정의 멤버 번호입니다. 서로 다를 수 있으니 **멤버는 이름으로** 찾으세요.

## 5. 지난 출력 보기 (스크롤·복사)

| 동작 | 방법 |
|---|---|
| 위로 스크롤 | **마우스 휠** (자동으로 복사 모드 진입) |
| 키보드로 복사 모드 진입 | `prefix [` |
| 복사 모드 이동 | `k`/`j` 한 줄, `Ctrl+u`/`Ctrl+d` 반 페이지, `g`/`G` 맨 위/맨 아래, `/` 검색 |
| 선택·복사 | `Space` 로 선택 시작 → 이동 → `Enter` 로 복사하고 나가기 (vi 기본 키) |
| 복사 모드 나가기 | `q` |

- 기록은 페인당 최근 100,000줄까지 남습니다.
- macOS 에서 마우스로 드래그해 복사하려면 `Option` 키를 누른 채 드래그합니다(tmux 마우스 모드 우회).

## 6. 멤버와 대화하기

**사용자는 진행-클로드와 이야기합니다.** 진행 파트가 멤버들에게 일을 나누고, 결정이 필요하면 결정 요청서를 올립니다.

1. 첫 창(발견 팀은 `발견`, 프로젝트 팀은 `기획`)의 **왼쪽 큰 페인(진행-클로드)** 을 클릭합니다.
2. 입력창에 요청을 쓰고 Enter.
3. 결정 요청이 오면 진행-클로드 페인에 답합니다 (예: "D-20261005-1 은 C 안으로 결정").

특정 멤버에게 직접 말하고 싶으면:

- 그 멤버 페인을 클릭하고 입력합니다. 단, **작업 중인 멤버**(Claude 는 `esc to interrupt`, Codex 는 `Working` 표시)에게 입력하면 작업 흐름이 섞일 수 있습니다. 가능하면 진행-클로드를 통해 전달하세요.
- 페인 밖(일반 터미널)에서 보내기: `team-send <이름> "메시지"` — 헤더에 `외부`로 표시됩니다.

멤버 페인에서 쓰는 명령:

| 동작 | Claude 멤버 | Codex 멤버 |
|---|---|---|
| 진행 중 작업 중단 | `Esc` | `Esc` |
| 컨텍스트 정리 | `/compact` | `/compact` |
| 상태(컨텍스트·한도) | `/context` | `/status` |
| 모델 바꾸기 | `/model` | `/model` |

> 다른 멤버의 작업 중 페인에 `/status` 같은 명령을 입력하지 마세요. 한도·컨텍스트는 아래 `team-status` 로 확인합니다.

## 7. 팀 상태 확인

```bash
team-status                 # 전 멤버 상태·창·컨텍스트, Codex 한도
team-status --tail 3        # 멤버별 마지막 3줄 미리보기
team-status --watch 10      # 10초마다 갱신 (Ctrl+c 로 종료)
team-status --limits        # Codex 5시간·주간 한도만
team-status --session shop  # 세션 지정
team-send -h                # 현재 세션의 멤버 이름·별칭 목록
```

| 표시 | 뜻 | 조치 |
|---|---|---|
| `[OK]` | 정상 동작 | — |
| `[INACT]` | 멤버 CLI 가 종료되고 셸만 남음 | 진행 파트가 보고함 → 세션 재생성 또는 해당 페인에서 재실행 결정 |
| Claude `⚠️ 70%+ used` / Codex `30% left 이하` | 컨텍스트 임계 | 진행 파트가 체크포인트 + `/compact` 지시 |
| Codex 5시간 한도 `⚠️ 30% 미만` · `🚨 10% 미만` | 사용 한도 부족 | 진행 파트가 선택지(대기 / 재배정 / effort 하향)를 올림 |

## 8. 자주 겪는 상황

| 상황 | 해결 |
|---|---|
| 화면이 멈춘 것 같다 | 복사 모드일 수 있음 — `q`. 페인 테두리 위에 `[0/123]` 같은 표시가 있으면 복사 모드 |
| 페인이 너무 작다 | `prefix z` 로 확대, 다시 `prefix z` 로 복귀. 또는 터미널 창을 크게 |
| 잘못 나눠진 페인을 닫고 싶다 | 팀 페인은 닫지 않는다 (멤버가 종료됨). 직접 만든 페인만 `prefix x` → `y` |
| `team-send` 가 "수신자 페인을 찾을 수 없습니다" | 세션 이름 확인(`tmux ls`), 이름·별칭 확인(`team-send -h`) |
| 세션을 새로 띄웠는데 예전 멤버 지시로 동작 | 역할 파일 변경은 **새로 띄울 때만** 반영 — 세션을 다시 만든다 |
| tmux 설정을 바꿨다 | `prefix r` 로 다시 읽기 (`~/.tmux.conf`) |

## 9. 단축키 요약

| 분류 | 단축키 |
|---|---|
| 세션 | `prefix d` 빠져나오기 · `prefix s` 세션 목록 · `prefix (` `)` 이전·다음 세션 |
| 창 | `prefix 1` `2` 번호 · `prefix n` `p` 다음·이전 · `prefix w` 트리 선택 · `prefix c` 새 창 |
| 페인 | 마우스 클릭 · `prefix h` `j` `k` `l` 이동 · `prefix q` 번호 · `prefix z` 확대/복귀 · `prefix H` `J` `K` `L` 크기 |
| 나누기 | `prefix \|` 좌우 · `prefix -` 위아래 (현재 폴더 유지) |
| 복사 | 마우스 휠 / `prefix [` → `Space` 선택 시작 → `Enter` 복사 · `q` 나가기 |
| 기타 | `prefix r` 설정 다시 읽기 · `prefix ?` 전체 단축키 보기 |
